# ExcuusExpert Start

Een snelle, persoonlijke startpagina voor je browser. Zoek via je favoriete zoekdienst, open je favoriete websites, of gebruik je recente zoekopdrachten. Je links, taken en voorkeuren blijven lokaal in je browser.

## Gebruiken

Open [excuusexpert.github.io](https://excuusexpert.github.io/) en voeg je eigen websites toe via **Snelkoppeling toevoegen**. Met `/` of `Ctrl+K` (op Mac `Cmd+K`) spring je naar het zoekveld. Een webadres opent direct; `!yt katten`, `!wiki ruimte` en `!maps Utrecht` zoeken direct op die bestemming.

## Als startpagina instellen

### Chrome

1. Open **Instellingen > Bij opstarten**.
2. Kies **Een specifieke pagina of set pagina's openen** en voeg `https://excuusexpert.github.io/` toe.
3. Voor de Home-knop: open **Weergave**, zet de Home-knop aan en vul dezelfde URL in.

Chrome laat de ingebouwde nieuwe-tabpagina niet vervangen door een gewone website. Daarvoor is een browserextensie nodig.

### Microsoft Edge

1. Open **Instellingen > Startpagina, startpagina en nieuwe tabbladpagina**.
2. Stel de startpagina-knop in op `https://excuusexpert.github.io/`.
3. Kies bij het starten voor deze pagina als je wilt dat Edge hem ook bij het opstarten opent.

Het nieuwe tabblad van Edge heeft eigen instellingen; een willekeurige website daarvoor instellen kan een extensie vereisen.

### Firefox

1. Open **Instellingen > Startpagina**.
2. Kies bij **Startpagina en nieuwe vensters** voor **Aangepaste URL's**.
3. Vul `https://excuusexpert.github.io/` in.

Firefox gebruikt voor nieuwe tabbladen een aparte instelling. Gebruik een compatibele extensie als je deze pagina bij elk nieuw tabblad wilt zien.

## Privacy en gegevens

- Zoekopdrachten worden rechtstreeks naar de gekozen zoekdienst gestuurd; deze site bouwt geen eigen zoekindex.
- Favorieten, taken, thema, zoekdienst en zoekgeschiedenis worden in `localStorage` op dit apparaat bewaard.
- De pagina vraagt niet om je locatie. Het weer gebruikt Amsterdam totdat je zelf een stad instelt.
- Er is geen analytics-script ingebouwd. Weer en geocodering gebruiken Open-Meteo wanneer die functies worden geladen of ingesteld.
- Gebruik **Instellingen > Data Back-up** om gegevens te exporteren of op een ander apparaat te importeren.
